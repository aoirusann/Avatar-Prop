# 旋转链路（Tracker + Contact + AimIK → 道具）

道具朝向的答案，来自**三个点**：`Hand`、`Middle finger`、`Ring finger` 三组 tracker 的最终位置；这三点由 `AimIK` 解成一组朝向。

## AimIK 的装配

`AimIK` 组件在路径 `Rotation/Get rotation/Rotation`：

```
transform  = Rotation        （被求解的节点本身）
target     = Middle finger    （瞄准目标）
poleTarget = Hand             （上方向 / pole）
axis = (0,0,1)   poleAxis = (0,1,0)   poleWeight = 1
```

而链根的位置由父物体 `Get rotation` 的 `VRCPositionConstraint` 决定：

```
Get rotation 源 = Ring finger : w1
```

于是三组 tracker 构成一个坐标架：

- **原点** = `Ring finger`
- **前方向（Z）** = 从原点到 `Middle finger` 的方向（AimIK 的 target）
- **上方向（Y）** = `Hand` 决定的 pole

> 两点定一条轴，第三点定滚转 —— 这就是为什么需要"手 + 中指 + 无名指"三个标签同时到位。

## 应用：Rotation 约束

道具朝向由一个 `VRCRotationConstraint`（在 `Position/Rotation` 上）驱动：

```
Rotation (VRCRotationConstraint) 源:
  source0 = Rotation        （AimIK 的输出节点）
  source1 = Save rotation   （锁存快照）
```

| 状态 | 主要来源 |
|---|---|
| Grabbed | source0 = `Rotation`（实时 AimIK 朝向） |
| Prop dropped | source1 = `Save rotation`（锁存，见 [11-锁存机制](./11-锁存机制.md)） |
| Off / Enabled | source0/1 由 clip 设定，未抓时朝向跟随 AimIK 节点的静止姿态 |

## 三点为什么可信：先看 tracker 怎么定位

AimIK 读的是 tracker 的**最终位置**，而 tracker 的位置又是由接触信号连续算出来的，详见 [04-Tracker位置与TrackerBlendTree](./04-Tracker位置与TrackerBlendTree.md)。另外系统还要用 [05-TrackerSync与TrackersCheck](./05-TrackerSync与TrackersCheck.md) 判断这个三点估计是否"收敛有效"。

## 完整顺序

```
手指接触 → DBT 算出 tracker 位置 → (Ring 当原点 / Middle 当 target / Hand 当 pole)
        → AimIK 解出 Rotation 的朝向 → 道具 Rotation 约束跟随
```
