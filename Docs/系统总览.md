# 系统总览

Avatar Prop 的目标是：在 avatar 上提供一个**可以被抓取、移动、旋转，并停放到世界里**的道具。它由三块拼起来：

1. **一个可抓的 PhysBone（手柄）** —— 负责"位置"。
2. **一套 Contact 追踪器 + AimIK** —— 负责还原"朝向"。
3. **一组靠动画切换来源权重的约束 + 一个 FX 状态机** —— 把道具接到手柄上，并管理"拿着/放下/复位"。

道具本体不是手柄的子物体，而是被约束"算"到手柄的位置和朝向上。

## 数据流一览

```
玩家手部碰撞体(标准 tag: Hand / FingerMiddle / FingerRing / FingerLittle)
        │ 抓取
        ▼
Bone (VRCPhysBone)  ───────────────► 提供"位置"
        │
        ▼
Tracker container 的 3 组 tracker (Hand / Middle / Ring)
        │  每指 5 个 ContactReceiver(Prox + X±Y±) 产出 0~1 浮点
        ▼
Tracker Blend Tree (DBT)  ──────────► 把接触图案算成 tracker 的位置
        │
        ▼
AimIK (原点=Ring, target=Middle, pole=Hand)  ──► 算出一组"朝向"
        │
        ▼
Position / Rotation 约束  ──────────► 把位置+朝向应用到道具网格
        │
        ▼
Avatar prop logic (状态机)  ─────────► 决定"跟手 / 停住 / 回原位 / 关闭"
```

## 内置控制器

Prefab 自带 3 个 controller，通过 VRCFury 的 **FullController** 并入 avatar 的 FX 层：

- `Avatar prop FX.controller`：含两层 —— `Avatar prop logic`（状态机）与 `Tracker Blend Tree`（Direct Blend Tree）。
- `Avatar prop FX Logic.controller`：与上一者的"logic"层同源。
- `Avatar prop FX DBT.controller`：与上一者的"Tracker Blend Tree"层同源。

构建时 `AvatarProp/*` 参数会被 VRCFury 加上 `VF123_` 前缀（见 [参数与接触标签](./参数与接触标签.md)）。

## 关键物体

```
Avatar Prop (根，被约束到世界锚点 000)
├─ Position → Rotation → Object container → 你的道具网格
├─ Tracker container → Hand / Middle finger / Ring finger / TrackerSync
├─ Rotation → Save rotation / Get rotation → Rotation(AimIK)
├─ Bone base → Bone(PhysBone) → Resyncy boi → Hand checker
│             Distance check → Distance checker
├─ Delay position
├─ Save position
├─ Reset transform（复位锚点；本 fork 被 ArmatureLink 到 Head 骨骼）
└─ Cull
```
