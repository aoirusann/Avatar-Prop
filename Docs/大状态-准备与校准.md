# 大状态：准备与校准

这一大状态处理"打开道具 → 让道具出现在复位点 → 张开传感器等待抓握"。包含 5 个小状态。

## Enabled

- clip：`On.anim`。
- 行为：`Object container` 显示、`Tracker container` 打开、三个 `Proximity` 打开、`Cull` 权重 1；tracker 保持小尺寸（ScaleConstraint `GlobalWeight=0`）；`Position` 源切到 `Resyncy boi`（此时手柄静止在复位点，所以看着也在复位点）；`Bone base` 约束关闭。
- 迁移：
  - `→ Expansion n Hand check`：`IsGrabbed` 为 true。
  - `→ On reset`：无额外条件，播出结束后自动进入。
  - `→ transition off → Off`：`Enable` 为 false。

## On reset

- clip：`On reset.anim`。
- 行为：与 `Enabled` 类似（道具显示、追踪打开、Prox 打开）。
- 迁移：`→ Reset root bone pos`（播出结束后）；`→ Expansion n Hand check`（`IsGrabbed`）；`→ transition off`（`Enable` 关）。

## Reset root bone pos（含 left / right）

- clip：`Right pos reset.anim` / `Left pos reset.anim`。
- 行为：把**手柄底座**（`Bone base`）重新对位——`Bone base` 约束打开并切到跟随道具 `Position`；`Save position` 被关闭；tracker 保持小尺寸；道具位置来源切到 `Save position`。
- 迁移：`→ Prop dropped …`（`DistanceTooFar` 为 false）；`→ Enabled 1 reset` / 由 `On reset` 链路继续。
- 作用：essentially 把"手柄"重新摆回一个可抓的基准位置，是启动/复位序列里的一步。

## Enabled 1 reset

- clip：`On 1.anim`。
- 行为：道具显示、追踪打开、`Cull` 权重 1、tracker 小尺寸——一个"等待抓握"的稳定态。
- 迁移：`→ Expansion n Hand check`（`IsGrabbed` 为 true）；`→ Off`（`Enable` 关）。

## Expansion n Hand check（进入检测状态）

- clip：`Expand.anim`。
- 行为：tracker 全开（`Tracker container`、三组 `Proximity`、`Hand checker` 都 active），tracker 保持小尺寸；`Bone` PhysBone 打开；`Cull` 权重 1。
- 作用：**张开所有接触传感器，等一个有效抓握**。当 `TrackersCheck` 为 true、且三个 `Prox > 0.57`、且判定出某只手时，进入 [大状态-被抓取Grabbed](./大状态-被抓取Grabbed.md)。抓握中途松开则去 `Prop dropped uncalibrated`；关掉开关则回 `Off`。

## 启动时序小结

```
Off ──Enable 开──► Enabled ──播出结束──► On reset ──► Reset root bone pos ──► Enabled 1 reset
                                                                    （等待）
  （若在这条链路中途就抓住：Enabled/On reset/Enabled 1 reset 可直接去 Expansion n Hand check）
```
