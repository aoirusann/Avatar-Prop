# 状态机总览

系统有**两层**：

- `Avatar prop logic`：状态机（本篇主讲）。
- `Tracker Blend Tree`：Direct Blend Tree，做连续计算，见 [Tracker位置与TrackerBlendTree](./Tracker位置与TrackerBlendTree.md)。

状态机的入口默认状态是 `Off`；但本 fork 里 `AvatarProp/Enable` 默认 = 1，所以加载后会立刻从 `Off` 迁到 `Enabled`（看上去就是"开机即显示"）。下面把十几个小状态归成**四个大状态**，每个大状态一篇文档。

## 四个大状态

| 大状态 | 包含的小状态 | 一句话 |
|---|---|---|
| 未激活 | `Off` | 道具隐藏、系统关 |
| 准备与校准 | `Enabled`、`On reset`、`Reset root bone pos (left/right)`、`Enabled 1 reset`、`Expansion n Hand check` | 打开、出现、并进入"检测抓握" |
| 被抓取 | `Grabbed with left/right hand`、`Grabbed with … transition off` | 已确认抓稳，跟手 + 出朝向 |
| 放下 | `Prop dropped left/right hand`、`Prop dropped uncalibrated`、`Reattach`、`… released reset…`、`… transition off` | 松手后停住；或抓不稳时重新校准 |

对应文档：[未激活Off](./大状态-未激活Off.md)、[准备与校准](./大状态-准备与校准.md)、[被抓取Grabbed](./大状态-被抓取Grabbed.md)、[放下PropDropped](./大状态-放下PropDropped.md)。

## 迁移总览

约定：`Enable` 指菜单参数 `AvatarProp/Enable`；`IsGrabbed` 指 `AvatarProp/Grabbing_IsGrabbed`。

```
Off ──(Enable 开)──► Enabled ──(IsGrabbed 开)──► Expansion n Hand check
                       │                                  │
                       │(Enable 关)          (三点 Prox>0.57 + TrackersCheck + 某只手)
                       ▼                                  ▼
                  transition off                      Grabbed (左/右)
                       │                                  │
                       │              (某 Prox<0.3 或 TrackersCheck 假)│
                       │                                  ▼
                       │                              Reattach ◄───────┐
                       │                                  │             │
                       │                       (IsGrabbed 关)          │
                       │                                  ▼             │
                       │                          Prop dropped (左/右) ─┘
                       │                                  │
                       │                 (DistanceTooFar)    (IsGrabbed 开 & Enable 开)
                       │                                  ▼
                       │                     Reset root bone pos (左/右)
                       │                                  │(DistanceTooFar 关)
                       │                                  ▼
                       │                          Enabled 1 reset / On reset ──► Expansion n Hand check
                       └────────────────────────────────────────────────────────────► Off
```

补充几条关键迁移条件（实测）：

- `Off → Enabled`：`Enable` 为 true。
- `Enabled → Expansion n Hand check`：`IsGrabbed` 为 true；`Enabled → On reset`（自动，播出结束）；`Enabled → transition off`：`Enable` 为 false。
- `Expansion n Hand check → Grabbed (左/右)`：`TrackersCheck` 为 true，且 `Hand/Middle/Ring` 三个 `Prox > 0.57`，且 `LeftHand > 0.5 & RightHand < 0.51`（右手反之）。
- `Grabbed → Reattach`：某个 `Prox < 0.3`，或 `TrackersCheck` 为 false。
- `Grabbed → Prop dropped`：`IsGrabbed` 为 false（松手）或 `Enable` 为 false。
- `Prop dropped → Reattach`：`IsGrabbed` 为 true 且 `Enable` 为 true（又抓住了）。
- `Prop dropped → Reset root bone pos`：`DistanceTooFar` 为 true。

绝大多数转移的 `duration = 0`（瞬时），这点在解释"尺寸突变"时很重要，见 [大状态-被抓取Grabbed](./大状态-被抓取Grabbed.md)。
