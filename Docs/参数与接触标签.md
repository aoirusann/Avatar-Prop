# 参数与接触标签

## 菜单参数

Prefab 自带菜单 `Prop menu` 只有**一个控件**：

| 菜单项 | 参数 | 类型 | 说明 |
|---|---|---|---|
| `Enable prop` | `AvatarProp/Enable` | Bool | 总开关（本 fork 默认 = 1） |

> 注意：它**没有** Reset 按钮。"复位"是状态机内部行为，见 [大状态-准备与校准](./大状态-准备与校准.md)。

## Animator 参数（构建后带 `VF123_` 前缀）

| 参数 | 类型 | 来源 | 作用 |
|---|---|---|---|
| `AvatarProp/Enable` | Bool | 菜单 | 总开关（default = 1，本 fork 默认开启） |
| `AvatarProp/Grabbing_IsGrabbed` | Bool | `Bone` PhysBone 的 Parameter | 是否被抓住 |
| `AvatarProp/LeftHand` / `RightHand` | Float | `Hand checker` 的 HandL / HandR Contact | 判定哪只手在抓 |
| `AvatarProp/DistanceTooFar` | Bool | `Distance check` 与 `Distance checker` 的 Contact | 距离判定 |
| `AvatarProp/TrackersCheck` | Bool | `TrackerSync` 的 Constant Contact | 抓握是否收敛有效 |
| `AvatarProp/Trackers/Blend` | Float | 计算 | tracker 融合强度 |
| `AvatarProp/Trackers/{Hand,Middle,Ring}/Prox` | Float | 对应 `Proximity` ContactReceiver | 抓握强度 |
| `AvatarProp/Trackers/{Hand,Middle,Ring}/{X+,X-,Y+,Y-}` | Float | 对应方向 ContactReceiver | 手指相对方向 |

其中 PhysBone 参数与 Contact 参数由 VRChat 自动生成，在本地与远端副本上都可用，**不需要**手动写进 Expression Parameters。

## 依赖的标准碰撞标签

系统依赖的标签全部是 VRChat 每个 avatar **默认自带**的手部碰撞体标签，因此别人不需要额外安装任何东西：

| 标签 | 用在哪 |
|---|---|
| `Hand` | `Hand` tracker 的 5 个接收器 |
| `FingerMiddle` | `Middle finger` tracker 的 5 个接收器 |
| `FingerRing`、`FingerLittle` | `Ring finger` tracker 的 5 个接收器 |
| `HandL`、`HandR` | `Hand checker` 用于区分左右手 |
| `AvatarProp.Distance` | `Resyncy boi` 发送、`TrackerSync` 接收 |
| `Avatarprop.DistanceCheck` | `Distance checker` 发送、`Distance check` 接收 |

> 标签区分大小写。`AvatarProp.Distance`（自定义抓握参考）与 `Avatarprop.DistanceCheck`（距离判定）是两个不同的标签。
